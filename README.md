## Project Description
This project is a menu-driven Python application designed to manage student academic records. It demonstrates the use of Python data structures such as tuples, lists, dictionaries, and sets, as well as functions, conditionals, and loops.

## Features
- View all student records
- Add a new student
- Check graduation eligibility
- Identify best-performing student
- Academic status evaluation
